# Xi Zhang — Personal Website

A static, multi-page portfolio for research, university roles, and other job applications.

- Website: https://zhxkylin.github.io/
- Contact: xizhang6@uvic.ca

## Pages

`index.html` is the homepage. `about.html`, `experience.html`, `research.html`, `photography.html`, `academic-work.html`, and `contact.html` are the main pages. The Academic Work hub links to four reserved subpages: `cv.html`, `writing.html`, `scholarly-activity.html`, and `teaching.html`.

To fill these pages later, replace the text inside each `.slot-empty` panel with verified entries and their dates or links. Remove the "SECTION RESERVED" label from a panel when it has content, then update the corresponding hub card's "PAGE RESERVED" label. For the CV, add a shareable PDF to the repository and link to it from `cv.html`; the present site does not link to a missing file. List presentations after they are confirmed and publications after they are published. The navigation is repeated in each HTML file; update it in all eleven pages if a page is added or renamed.

Selected photographs are in `assets/photography/`; the photo gallery links to those image files. Shared design is in `styles.css`, and the mobile menu and footer year are in `script.js`.

Changes committed to `main` are published by GitHub Pages. The public site does not include a phone number, referee details, or a job-specific résumé. There are no analytics or contact forms.
